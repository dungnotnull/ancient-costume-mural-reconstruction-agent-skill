# Evidence Hierarchy Protocol — Ancient Costume Reconstruction

## Overview

This document defines the **evidence hierarchy** used in ancient costume reconstruction.
It specifies how different types of evidence are weighted and combined to produce
the most accurate reconstructions possible.

---

## The Hierarchy (Tier System)

### Tier 1: Extant Textiles (Highest Priority)

**When extant textiles survive, they ALWAYS trump iconographic inference.**

**Definition:** Archaeologically recovered garments, textile fragments, or
surviving historical garments from the target period/culture.

**Weighting:**
- Pattern geometry: 100% (this is how it was actually made)
- Construction method: 100% (seams, fastenings, assembly)
- Materials: 100% (fiber identification, weave structure, dyes)
- Color: 80-100% (account for fading/deterioration)

**Usage Rules:**
1. **Direct application:** If extant example exists, use it directly
2. **Parallel application:** If similar example exists, adapt with caution
3. **Hierarchical application:** Extant > Iconographic > Textual > Ethnographic

**Examples:**
- Han dynasty silk fragments from Mawangdui tombs
- Tang dynasty garments from Astana cemetery
- Song dynasty textiles from Famenkong tomb

---

### Tier 2: Iconographic Sources (Visual Evidence)

**Iconography provides form, drape, and layering information.**

**Definition:** Murals, tomb paintings, Buddhist cave art, statuary, reliefs,
manuscript illuminations, painted artifacts.

**Weighting:**
- Overall silhouette: 80-90% (usually reliable)
- Sleeve/shoulder treatment: 70-80% (may be stylized)
- Layering sequence: 60-70% (visible layers are real, hidden layers inferred)
- Color: 40-70% (depends on preservation, artistic convention)
- Pattern detail: 30-60% (may be symbolic)

**Critical Analysis Required:**
1. **Realism vs. Convention:** Is this showing actual dress or symbolic elements?
2. **Period Style:** Artistic conventions change over time (Han vs. Tang vs. Song)
3. **Viewpoint Limitations:** Single-view sources require inference for unseen angles
4. **Color Fidelity:** Pigments fade; artistic colors ≠ textile colors

**Usage Rules:**
- Use for garment FORM and SILHOUETTE
- Use for LAYERING (visible layers only)
- Use for ACCESSORIES (if clearly depicted)
- CAUTION on COLORS (verify with extant examples when possible)
- CAUTION on PATTERNS (may be symbolic)

---

### Tier 3: Textual Sources (Written Evidence)

**Textual sources provide context but require verification.**

**Definition:** Historical texts, tomb inscriptions, bureaucratic records,
treatises, literary descriptions.

**Weighting:**
- Garment terminology: 50-70% (terms may be specific or generic)
- Color terminology: 40-60% (color words vary in meaning over time)
- Construction details: 30-50% (texts rarely describe construction clearly)
- Regulations/sumptuary laws: 80-90% (prescriptive, accurate for rules)

**Critical Analysis Required:**
1. **Genre:** Legal text (high accuracy) vs. literary text (metaphorical)
2. **Audience:** Who wrote this? For whom? (affects reliability)
3. **Date:** Is this contemporary or later retrospective account?
4. **Terminology:** Do garment terms match archaeological examples?

**Usage Rules:**
- Use for SOCIOCULTURAL CONTEXT (rank, occasion, symbolism)
- Use for REGULATIONS (sumptuary laws, dress codes)
- Use for CHRONOLOGY (when styles changed)
- SUPPLEMENT with visual/archaeological verification

---

### Tier 4: Ethnographic Parallels (Caution Required)

**Ethnographic sources suggest possibilities but not certainties.**

**Definition:** Later traditional dress, cross-cultural parallels,
ethnographic analogy.

**Weighting:**
- General techniques: 30-50% (may preserve ancient methods)
- Specific patterns: 10-30% (unlikely to preserve specific ancient designs)
- Color symbolism: 20-40% (may change dramatically over time)

**Critical Analysis Required:**
1. **Time Gap:** How many centuries separate the ethnographic source?
2. **Cultural Continuity:** Is there demonstrated cultural continuity?
3. **Selection Bias:** Are we cherry-picking convenient parallels?

**Usage Rules:**
- Use for GENERAL TECHNIQUES (weaving, dyeing methods)
- Use as LAST RESORT when no better evidence exists
- ALWAYS FLAG as SPECULATIVE

## Evidence Combination Rules

### Rule 1: Extant-Textile-First

**When extant textiles exist, they govern the reconstruction.**

```
IF extant textile from target period/culture available:
    Use directly (100% confidence on form/construction/materials)
    Adjust for status differences if applicable
    Iconography used only for accessories/details not preserved

ELSE IF similar extant textile available (near period/related culture):
    Adapt with caution (70-80% confidence)
    Note differences in period/culture
    Flag adaptations explicitly

ELSE:
    Proceed to Tier 2 (iconography)
```

### Rule 2: Iconography with Extant Verification

**Iconography is most reliable when corroborated by extant examples.**

```
IF iconographic element confirmed by extant example:
    Confidence increases to 80-90%
    Apply to reconstruction with high confidence

IF iconographic element unconfirmed but plausible:
    Confidence remains 60-70%
    Flag as interpretation

IF iconographic element contradicted by extant example:
    Extant example takes priority
    Iconography marked as stylized/symbolic
```

### Rule 3: Textual Integration

**Textual sources supplement visual/archaeological evidence.**

```
IF textual description matches iconography/extant example:
    Strengthens confidence in both sources
    Use to explain CONTEXT (symbolism, occasion, rank)

IF textual description contradicts visual evidence:
    Examine genre (legal vs. literary)
    Examine date (contemporary vs. retrospective)
    Usually, visual/archaeological evidence trumps literary
```

### Rule 4: Ethnographic Caution

**Ethnographic parallels are suggestive, not definitive.**

```
IF ethnographic source used:
    MUST flag as SPECULATIVE
    MUST explain time gap and cultural discontinuity
    MUST provide alternative interpretations
    Confidence cap: 50%
```

## Conflict Resolution

### When Evidence Types Conflict

**Priority Order:**
1. Extant textile (Tier 1)
2. Iconography (Tier 2) — if realistic depiction
3. Textual source (Tier 3) — if prescriptive/legal text
4. Ethnographic parallel (Tier 4) — lowest priority

**Examples:**

| Conflict | Resolution | Reasoning |
|----------|-----------|-----------|
| Iconography shows red robe, extant is originally blue | Extant wins | Pigment faded, chemical analysis more reliable |
| Text says "wide sleeves," iconography shows narrow | Iconography wins | Text may be generic term; visual is specific |
| Text describes complex brocade, none in iconography | Text wins | Brocade may not be visible in art style |

## Confidence Grading

### Assigning Confidence Grades

For each reconstruction element, assign confidence based on evidence:

| Confidence | Evidence Required | Example |
|------------|-----------------|---------|
| **H (High)** | Direct extant example OR multiple iconographic sources + extant confirmation | Pattern shape from extant tomb garment |
| **M (Medium)** | Single good iconographic source OR textual + iconographic agreement | Sleeve type from clear mural depiction |
| **L (Low)** | Fragmentary evidence OR ethnographic analogy OR required inference | Back view from single front-view source |

### Composite Confidence

For the overall reconstruction:

```
IF all elements High:
    Overall: Evidence-Based Reconstruction
    Confidence: High

IF mix of High and Medium:
    Overall: Evidence-Based Reconstruction (with caveats)
    Confidence: Medium-High

IF any Low elements:
    Overall: Plausible (interpretive) OR Speculative
    Confidence: Medium OR Low
```

## Disclosure Requirements

### When to Disclose

**ALWAYS disclose limitations:**
1. Before any verdict/conclusion
2. When confidence is Medium or Low
3. When using ethnographic analogy
4. When inferring from single-view sources
5. When colors are faded/uncertain
6. When reconstruction involves significant conjecture

### What to Disclose

**Minimum disclosure elements:**
1. What evidence types were used
2. What evidence is missing
3. What elements are speculative
4. What alternative interpretations exist
5. What would improve confidence

## Examples: Applying the Hierarchy

### Example 1: Tang Dynasty Court Robe

**Evidence Available:**
- Iconography: Tomb murals (clear, multi-figure)
- Extant: Similar robe from Astana cemetery (slightly later)
- Textual: Tang regulations on court dress

**Reconstruction Approach:**
1. Pattern: Adapt from extant Astana example (Tier 1) → H confidence
2. Colors: Use mural colors with fading adjustment, confirmed by extant → M-H confidence
3. Rank badges: Follow textual regulations (Tier 3) → M confidence
4. Back view: Inferred from front view + extant parallels → M confidence

**Overall:** Evidence-Based Reconstruction, Medium-High confidence

---

### Example 2: Han Dynasty Noblewoman's Garment

**Evidence Available:**
- Iconography: Mawangdui tomb painting (single view)
- Extant: Silk fragments from same tomb (Tier 1)
- Textual: Han dynasty sumptuary laws

**Reconstruction Approach:**
1. Materials: Use extant silk analysis (Tier 1) → H confidence
2. Pattern: Adapt from extant fragments + iconography → H confidence
3. Colors: Use extant dye analysis + mural → H confidence
4. Construction: Seams from extant fragments → H confidence

**Overall:** Evidence-Based Reconstruction, High confidence

---

### Example 3: Song Dynasty Commoner's Dress

**Evidence Available:**
- Iconography: Genre paintings (multiple figures)
- Extant: No direct surviving examples
- Textual: References to common dress in literature

**Reconstruction Approach:**
1. Form: Use iconography (multiple sources) → M confidence
2. Materials: Infer from period capabilities (no extant) → M-L confidence
3. Colors: Use painting colors (likely symbolic) → L confidence
4. Construction: Infer from period techniques → M confidence

**Overall:** Plausible (interpretive), Medium confidence
